# Aditya Raj - Operations & Business Analyst Portfolio

A modern, highly interactive web portfolio showcasing professional achievements, analytics expertise, and operational research projects. Inspired by high-end design aesthetics (dark theme, viewport frames, custom cursor, and dynamic scroll animations).

## 🚀 Live Site
The site is hosted on GitHub Pages:
👉 **[https://naman-pasricha.github.io/Aditya-Portfolio-Test-1/](https://naman-pasricha.github.io/Aditya-Portfolio-Test-1/)**

## 🛠️ Technology Stack
- **Core**: HTML5, Vanilla JavaScript (ES6+), CSS3 custom design system.
- **Typography**: Bricolage Grotesque (Headers/Display) & Inter (Body/Labels).
- **Icons**: Lucide Icons.
- **Deployment**: GitHub Actions & GitHub Pages.

## 📁 Key Features
- **Modern Dark/Slate Theme**: Built with a sleek `#0A0A0A` page background and an accent Slate Blue color scheme.
- **Dynamic Scroll Animations**: Clean scroll-reveal transitions on sections.
- **Custom Cursor Follower**: Reactive custom cursor follower that provides contextual feedback (`View`, `Go`, `Mail`, etc.).
- **Viewport Framing**: CSS-based navigation frame and overlays keeping key links accessible.
